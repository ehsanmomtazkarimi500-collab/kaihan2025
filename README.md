# راه‌اندازی کیهان (PWA آفلاین + داده مشترک در Google Drive)

## ۱) انتشار روی GitHub Pages
1. در GitHub یک مخزن (Repository) بسازید، مثلاً `keyhan` (پیشنهاد: Private نباشد؛ داده‌ها در مخزن نیستند و فقط در Drive می‌مانند).
2. همهٔ فایل‌های این پوشه را آپلود کنید (Add file ← Upload files؛ پوشهٔ `fonts` هم باشد).
3. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / root ← Save.
4. بعد از چند دقیقه آدرس `https://USERNAME.github.io/keyhan/` فعال می‌شود.

## ۲) ساخت Client ID گوگل (یک‌بار، رایگان)
1. در console.cloud.google.com یک پروژه بسازید.
2. APIs & Services ← Library ← **Google Drive API** را Enable کنید.
3. OAuth consent screen: نوع External، نام برنامه «کیهان»، ایمیل خودتان. در بخش **Test users** ایمیل خودتان و همکاران را اضافه کنید.
4. Credentials ← Create credentials ← OAuth client ID ← نوع **Web application**.
   در Authorized JavaScript origins فقط این را بنویسید: `https://USERNAME.github.io`
5. Client ID را در `config.js` بین کوتیشن‌های `CLIENT_ID` بگذارید و فایل را در GitHub ذخیره کنید.

## ۳) پوشهٔ مشترک Drive
1. در Google Drive یک پوشه بسازید (مثلاً «کیهان - اطلاعات») و با ایمیل همکاران، دسترسی **Editor** بدهید.
2. لینک پوشه را کپی کنید.
3. در برنامه: دکمهٔ «🔄 همگام‌سازی» ← لینک را بچسبانید ← «ذخیره و اتصال» ← با حساب Google وارد شوید.
   (هر همکار همین کار را یک‌بار روی دستگاه خودش انجام می‌دهد. اگر خواستید، `FOLDER_ID` را در `config.js` بگذارید تا لینک خودکار پر شود.)

چون برنامه در حالت آزمایشی است، هنگام ورود هشدار «unverified app» می‌بینید: Advanced ← Continue.

## ۴) انتقال داده‌های فعلی
- **از نسخهٔ آنلاین فعلی (Apps Script):** در آن برنامه «⬇ پشتیبان» را بزنید، در برنامهٔ جدید «⬆ بازیابی» و فایل را انتخاب کنید. سپس همگام‌سازی را اجرا کنید.
  تصاویر فیش‌هایی که به Drive صاحب اسکریپت ارجاع دارند فقط برای همان حساب باز می‌شوند.
- **اگر برنامه را روی همان آدرس قبلی باز کنید:** داده‌های localStorage خودکار به IndexedDB منتقل می‌شوند (حذف نمی‌شوند).
- قبل از حذف نسخهٔ قدیمی، تعداد حساب‌ها و جمع مبالغ را با هم مقایسه کنید.

## ۵) نصب روی گوشی/کامپیوتر
Chrome ← منو ← Install app / Add to Home screen.

## قواعد همگام‌سازی
- هر تغییر ابتدا روی دستگاه ذخیره می‌شود (آفلاین هم کار می‌کند) و بعد از چند ثانیه با Drive ادغام می‌شود.
- اگر دو نفر همزمان یک ردیف را ویرایش کنند، ویرایش جدیدتر می‌ماند؛ ردیف‌های دیگر دست‌نخورده‌اند.
- «پاک‌سازی کامل» با همگام‌سازی فعال برای همه اعمال می‌شود.
